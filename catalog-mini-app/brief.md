## 1. Список экранов

### Экран 1: Splash / Загрузка

**Элементы:** Логотип / имя мастера по центру, skeleton-анимация если загрузка > 300мс

**Действия:** Нет — автоматический экран

**Переходы:**

### Экран 2: Главная (Каталог категорий)

**Элементы:**

*Шапка:*
- Круглое фото мастера (56px)
- Имя мастера + город
- Иконки: Портфолио (📷) и О мастере (ℹ️) — 44px каждая

*Блок "Ближайший слот":*
- "Ближайшее время: завтра, 14:00"
- Кнопка "Записаться сейчас" (100% ширины, 52px)

*Сетка категорий:*
- 2 колонки, карточки с фоновым фото + название поверх
- Категории: Маникюр, Педикюр, Дизайн, Уход, Наращивание

*Bottom Tab Bar (56px):*
- 4 вкладки: Главная · Записи · Портфолио · Мастер

**Действия / Переходы:**
- Тап на категорию → **Список услуг**
- Тап "Записаться сейчас" → **Карточка услуги** (ближайший слот предвыбран)

- Вкладка "Записи" → **Мои записи**
- `tg.BackButton.hide()` — на главной кнопки "назад" нет

### Экран 3: Список услуг (по категории)

**Элементы:**

*Шапка:* Название категории + `tg.BackButton`

*Фильтры (горизонтальный скролл):*
- Чипсы: "Все", "Гель-лак", "Арт-дизайн", "Экспресс" (высота 36px, tap-зона 44px)

*Карточки услуг:*
- Фото 88×88px слева + название (16px жирный) + описание (1 строка, серый) + цена (акцент) + длительность (иконка часов)
- Минимальная высота карточки: 88px

**Действия / Переходы:**
- Тап на карточку → **Карточка услуги**
- Тап фильтра → фильтрация без перезагрузки
- BackButton → **Главная**

### Экран 4: Карточка услуги

**Элементы:**

- Полноширинное фото (4:3, ~280px) со свайпом + точки-индикатор
- Название (H1, 20px), цена + длительность (крупно, акцент + иконка)
- Описание (3–5 строк, "Читать далее")
- Фото мастера (32px) + имя + кнопка "Написать"
- Чипсы вариантов: "Короткие / Средние / Длинные" (меняют цену)
- Горизонтальный скролл миниатюр работ (80×80px)

*MainButton:* "Записаться — 2 200 ₽"

**Действия / Переходы:**
- MainButton → **Выбор даты**
- Тап варианта (чип) → пересчёт цены в MainButton
- Тап миниатюры → полноэкранная галерея
- Тап "Написать" → `tg.openTelegramLink` → чат с мастером
- BackButton → **Список услуг**

### Экран 5: Выбор даты

**Элементы:**

- Строка шагов: "Услуга ✓ → **Дата** → Время → Оплата"
- Recap-полоска: миниатюра + название + цена выбранной услуги
- Быстрый выбор: "Ближайшая дата: завтра" (кнопка-тег)
- Календарь с навигацией по месяцам
  - Доступен: белый, кликабелен (44×44px)
  - Занят: серый, не кликабелен
  - Выбранный: заливка `button_color`

*MainButton:* "Выберите дату" (задисаблена) → после выбора: "Выбрать время →"

**Действия / Переходы:**
- Тап на доступную дату → MainButton активируется
- MainButton → **Выбор времени**
- Стрелки месяца → смена месяца + загрузка доступности
- BackButton → **Карточка услуги**

---

### Экран 6: Выбор времени

**Элементы:**

- Recap-полоска: услуга + выбранная дата (кликабельна для возврата)
- Подсказка: "Осталось 2 слота сегодня" (если мало)
- Сетка слотов (3 колонки, минимум 52×52px):
  - Свободно: белый фон
  - Занято: серый + "занято", не кликабелен
  - Выбран: заливка `button_color`

*MainButton:* "Выберите время" (задисаблена) → после выбора: "Продолжить — Пт, 14 мая · 14:00"

**Действия / Переходы:**
- Тап на слот → слот выделяется, MainButton активируется; Redis lock TTL 5 мин
- MainButton → **Подтверждение записи**
- Тап recap-даты → **Выбор даты**
- BackButton → **Выбор даты**

### Экран 7: Подтверждение записи

**Элементы:**

*Карточка-итог:*
- Фото мастера (48px) + имя
- Услуга + вариант
- Дата и время (крупно, жирно)
- Адрес мастера
- Длительность: "~75 минут"

*Блок клиента:*
- Имя из Telegram (предзаполнено)
- Если нет телефона: "Добавить номер" → `tg.requestContact()`
- Поле "Комментарий" (необязательно, 150 символов)

*Внизу серым:* "Отмена бесплатна за 24 часа до визита"

*MainButton:* "Оплатить депозит 500 ₽" / "Подтвердить запись"

**Действия / Переходы:**
- MainButton → **Оплата депозита** (или **Успешная запись** без депозита)
- Тап "Добавить номер" → `tg.requestContact()`
- Тап дата/время → **Выбор даты**
- BackButton → **Выбор времени**

## 5. Порядок разработки

### Этап 0: Фундамент (3–5 дней)
- Vite + React + TypeScript + `@twa-dev/sdk`
- `tg.themeParams` → CSS-переменные
- Memory History Router + Bottom Tab Bar
- BackButton: глобальный обработчик
- Backend: Fastify + Prisma + PostgreSQL схема
- Валидация `initData` (HMAC-SHA256) на каждом запросе
- Деплой: Cloudflare Pages + Railway

### Этап 1: Каталог (5–7 дней)
- API: профиль мастера, категории, услуги
- Экраны: Главная, Список услуг, Карточка услуги
- Портфолио: сетка + lazy loading + lightbox
- О мастере
- Загрузка фото в Cloudflare R2

### Этап 2: Флоу записи (7–10 дней)
- API: доступность по дням, слоты, черновики записей
- Экраны: Выбор даты, Выбор времени, Подтверждение, Успех
- Redis блокировка слотов (TTL 5 мин)
- Бот-уведомления: клиенту + мастеру
- Экран Мои записи + Карточка записи + отмена

### Этап 3: Оплата (3–5 дней)
- Подключение Robokassa/ЮKassa → `provider_token`
- API: создание Invoice → `invoice_link`
- `tg.openInvoice(link, callback)`
- Webhook: `pre_checkout_query` + `successful_payment`
- Обработка ошибок оплаты

### Этап 4: Админ-панель (5–7 дней)
- API только для `master_id`: записи, расписание, CRUD услуг
- Экраны: Сегодня, Записи, Услуги, Настройки
- Бот-команда `/admin` → открытие панели

### Этап 5: Полировка (3–4 дня)
- Все пустые состояния и ошибки
- Skeleton-загрузчики везде
- Тест iOS: `100vh` → `tg.viewportStableHeight`
- Тест Android: системная кнопка "назад"
- Замер флоу: Главная → Успех < 60 сек
- Sentry на frontend и backend

**Итого: ~26–38 рабочих дней (5–8 недель)**

---

## Памятка разработчику

1. Никогда не использовать `100vh` — только `tg.viewportStableHeight`
2. Валидировать `initData` HMAC-SHA256 на каждом запросе к backend
3. Таймзоны: хранить UTC, показывать через `Intl.DateTimeFormat`
4. Блокировка слотов: Redis lock TTL 5 мин при выборе времени
5. Платёж: только через `tg.openInvoice()` → webhook → подтверждение
6. Навигация: Memory History (не Hash Router, не URL)
7. `localStorage` ненадёжен → черновик записи хранить на сервере
8. BackButton Android: перехватывать через `tg.BackButton`
